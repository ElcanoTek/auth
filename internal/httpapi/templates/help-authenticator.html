Set up two-factor sign-in

A step-by-step guide to adding your {{.Brand}} account to an authenticator app. It takes about five minutes.

What two-factor sign-in is

Two-factor sign-in means two things are needed to get into your account: your password, and a six-digit code from an app on your phone. The code changes every 30 seconds, so a code someone copies stops working almost at once.

Why it matters

  • Passwords get stolen. They leak when other websites are breached, they get reused, and they get typed into fake sign-in pages.
  • AI makes fake emails hard to spot. A scammer can now write a polished message that mentions your company, your clients or your colleagues, and build a convincing copy of a sign-in page, in minutes.
  • Busy seasons are scam seasons. Phishing and account takeovers peak when everyone is busiest, above all from Black Friday through the end of the year, which is also when campaigns matter most. That is the worst time to lose access to an account.
  • A stolen password is no longer enough on its own. With two-factor sign-in on, someone would also need the current code from your phone. That is also why a code should only ever go into the real sign-in page: a fake page can pass on a code you type into it.
Keep your codes to yourself. {{.Brand}} will never ask for a code by email, chat or phone. Only type one into the sign-in page{{if .Host}}, and check that the address bar shows {{.Host}}{{end}}.

What you need

Your phone, with one of these apps installed. All of them work; pick the one you already use, or Google or Microsoft Authenticator if you have none.

  • Google Authenticator (iPhone and Android). Free.
  • Microsoft Authenticator (iPhone and Android). Free.
  • Bitwarden Authenticator (iPhone and Android). Free, no account needed. Codes can also live in Bitwarden Password Manager, which needs a Premium or paid organization plan to show them.
  • 1Password (phone and computer). Included in every 1Password plan.

Apple Passwords, Authy, Duo Mobile and other apps work too: look for an option to scan a QR code or to enter a setup key.

What the set-up page shows

After your password, the set-up page shows three things:

  1. The QR code. Your authenticator app scans it with the phone's camera.
  2. The setup key, 32 letters and numbers. If you cannot scan, you type or paste this into your authenticator app. It never goes in the code box.
  3. The code box. Once the app has the account, type the six-digit code it shows here.

The set-up code lasts ten minutes. If it runs out, the page shows a new one.

Three ways to add the account

1. Scan from a computer

The set-up page is open on your computer. In your app, tap +, choose to scan a QR code, and point the phone at the screen.

2. On the same phone

You cannot scan your own screen. Tap the setup key once to select it and copy it. In your app, tap +, choose to enter a setup key, paste it, and pick Time based if asked.

3. A password manager on your computer

1Password (desktop app or browser extension) and the Bitwarden browser extension can read the QR code straight off your screen, then fill in codes for you when you sign in.

App by app

Button names can change a little between app versions. Each section links to the app maker's own guide, with pictures.

Google Authenticator

Scan the QR code

  1. Open Google Authenticator and tap + (bottom right).
  2. Tap Scan a QR code and point the camera at the QR code.

Or enter the setup key

  1. Tap +, then Enter a setup key.
  2. Account: type {{.Issuer}}. Key: paste the setup key. Type of key: Time based.
  3. Tap Add.

Google's guide to Authenticator (opens in a new tab)

Microsoft Authenticator

Scan the QR code

  1. Open Microsoft Authenticator and tap + (top right).
  2. Choose Other account (Google, Facebook, etc.). Not "Work or school account": that one is for Microsoft sign-ins.
  3. Point the camera at the QR code.

Or enter the setup key

  1. Tap +, then Other account (Google, Facebook, etc.).
  2. On the camera screen, tap Enter code manually.
  3. Account name: type {{.Issuer}}. Secret key: paste the setup key. Tap Finish.

Microsoft's guide to adding other accounts (opens in a new tab)

Bitwarden

Bitwarden Authenticator app (free)

  1. Tap the add icon (+) and point the camera at the QR code. Or tap Enter key manually at the bottom, type {{.Issuer}} as the name and paste the setup key as the authenticator key.
  2. Choose Save here (or Save to Bitwarden to keep it with your passwords).

Bitwarden Password Manager (Premium or paid organization plan)

On a free Bitwarden account the Password Manager saves the key but does not show codes, so use the free Bitwarden Authenticator app above instead.

  1. Open or create the login for {{.Brand}} and tap Edit.
  2. On a phone, tap Set up TOTP to scan the QR code, or Enter key manually to paste the setup key. In the browser extension, select TOTP to read the QR code from the open page (the whole code must be visible), or paste the key into Authenticator key.
  3. Save.

Bitwarden Authenticator guide (opens in a new tab) · Password Manager guide (opens in a new tab)

1Password

Phone or desktop app

  1. Open or create the login for {{.Brand}} and select Edit.
  2. Select Add More, then One-Time Password (you may need to scroll).
  3. Select the QR code icon: on a phone it opens the camera, on a computer it reads the QR code from your screen. Or paste the setup key into the field instead.
  4. Select Save.

Browser extension

  1. With the set-up page open, select the login for {{.Brand}} in the extension.
  2. Select the ⋯ menu, then Scan QR Code.

1Password then fills in the code for you at sign-in. 1Password's guide (opens in a new tab)

Finish and save your recovery codes

Opened this guide from the set-up page? It is in a new tab: switch back to the set-up tab to enter the code.

  1. Type the six-digit code from your app into the code box and select Turn on two-factor sign-in. If the code is about to change, wait for the next one.
  2. Save the ten recovery codes you see next. They are shown once. Each one signs you in a single time if you lose your phone, so keep them somewhere safe, such as your password manager.
  3. From now on, sign in with your password and then the current code from your app.

If something goes wrong

"Please match the requested format" or "That looks like the setup key"
The setup key was typed into the code box. The key goes into your app; the box takes the six digits the app shows.
"That code did not match" or "That code did not work"
Codes depend on your phone's clock. Set the date and time to automatic in your phone's settings, then try the current code.
"That set-up code expired"
Set-up codes last ten minutes, so the page now shows a new one. Add it as a new entry, and once it works, delete the older entries.
Your app lists {{.Issuer}} more than once
Only one of the entries works. Try the other one, then delete the one that fails.
New phone
Before you reset the old phone, move your codes with your app's transfer, backup or export option: Google Authenticator, Microsoft Authenticator and Bitwarden Authenticator (for codes saved only on the phone) each have one. Codes kept in 1Password or in your Bitwarden vault sync on their own.
Lost phone
Sign in with one of your recovery codes, then set up a new app from Security. No recovery codes left? Ask your administrator to reset two-factor sign-in for your account.
